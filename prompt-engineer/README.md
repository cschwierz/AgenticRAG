This LLM can generate and refactor Prompts. It is instructed to do so in `system-prompt.txt`

Insert Prompts in `template.txt` and additional context (like accurate instructions for the new Prompt) in `context.txt`

Insert a simple instruction for the prompt engineer in `query`, where you mention `template.txt` and `context.txt`

Execute `main.py` in the terminal and it prints out a new prompt
