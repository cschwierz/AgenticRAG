# RAG-Pipeline

pipeline for agentic RAG

## Components

-**Agent** with chat interface. it can use RAG as a tool and has the ReAct logic
-**RAG Pipeline** takes tool calls from the Agent as a query and returns Chunks from the Chroma DB as a response.
-**Ingestion** to create and fill the Chroma DB
	-ingestion will be worked on later. now i have a given DB
-**Open-WebUI** implementation for the GUI
	-will be worked on, once the framework is ready.
